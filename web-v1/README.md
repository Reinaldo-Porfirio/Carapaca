# Carcaça — Circuito Fornalha

Jogo 3D de arena de mechas que roda no navegador (three.js, sem servidor).

## Compilar
    npm install
    npm run build        # gera dist/index.html (arquivo único) e dist/artifact.html

## Versões
- **1.0** — primeira versão jogável: Circuito (18 rivais), Contratos, Modo Infinito, garagem, loja, 5 arenas.

Para voltar à 1.0: `git checkout v1.0` (ou extraia o pacote carcaca-v1.0.tar.gz).
